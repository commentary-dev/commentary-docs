Start with the symptom below. If the fix does not resolve it, note the review URL or object id, action, timestamp, and safe diagnostic code. Do not send tokens, secrets, private source text, or raw provider URLs in a support request.

- [I cannot open a repository or file](help/troubleshooting.md#repository-access)
- [A file or rendered section is missing](help/troubleshooting.md#rendering-and-history)
- [My comment has not appeared in the provider](help/troubleshooting.md#provider-sync)
- [An exact historical comparison is unavailable](help/troubleshooting.md#rendering-and-history)
- [A draft revision failed to upload](help/troubleshooting.md#draft-upload)
- [A Live Preview is blank or disconnected](help/troubleshooting.md#live-preview)
- [A Form cannot be submitted or its results are hidden](help/troubleshooting.md#forms)
- [An API/MCP write conflicts or is rejected](help/troubleshooting.md#api-and-mcp)
