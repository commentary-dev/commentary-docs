# Release walkthrough

## Outcome

Review the rollout plan and decide whether its checks are complete.

## Rollout checklist

- [ ] Confirm the preview matches the intended release.
- [ ] Record the rollout owner and support contact.
- [ ] Verify that the previous release can be restored.

Read the [rollout details](details.md), then leave feedback on the exact section
that needs clarification. A resolved comment is not a formal release approval.
