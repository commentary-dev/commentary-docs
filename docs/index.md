# Commentary Docs

Commentary is the human decision layer for AI agents. It turns Markdown, HTML,
Forms, repository changes, and interactive previews into document-first review
surfaces where people can understand context, comment precisely, and make explicit
decisions.

## October 2026 Updates

Public GitHub pull requests remain readable without signing in. Authentication is
required for comments, replies, private content, workspace administration, review
submission, and developer access. GitHub App and Microsoft Entra are the primary
provider connections; personal access tokens remain advanced recovery options.

For API, MCP, CLI, and agent integrations, continue with [Developer
access](developer-access.md), [API and MCP](api-and-mcp.md), or [Commentary
CLI](commentary-cli.md).
