# Request exact human acceptance and review changes

Acceptance binds an existing Interaction Decision to the exact Session, Resource, source, requirement and evidence revision set and proposed action. Eligible signed-in humans decide in Inbox under current policy. Agents request/read acceptance and report Fulfillment; they cannot create, import or patch human approval, reviewer eligibility or provider authority.

Before requesting, read the full authorized manifest, select the exact scope and explain consequences, supporting evidence and residual risk. An incomplete filtered target list is not an acceptance set. Membership changes, role loss, expiry and revocation can make a chain unsatisfiable; repair eligibility with the human manager rather than substituting an agent.

## What changes invalidate

New material revisions can make current acceptance stale. Prior receipts remain historical. Impact follows exact scoped targets/support and deterministic material changes, not a mutable timestamp or agent assertion. Merely equivalent material is assessed by the authoritative projection; do not infer currency from an event name or unchanged title.

**Since your last visit** compares an immutable private visit receipt with exact current snapshots. It does not silently fall back to All PR changes or reorder force pushes. If the exact baseline is unavailable, recover explicitly. Preserve Preview/Raw while selecting a comparison. Technical scope/digests stay behind disclosure.

Live Tracker embeds inside historical pages are labeled Live tracker and excluded from document acceptance. Export a bounded inert Tracker snapshot, save it in an immutable revision and explicitly select that target if those records should be accepted.

After correction, publish ready revisions, preserve unaffected targets, read the new manifest and request a fresh Decision. A successful CI run, artifact publication, reply, Board move or agent completion report cannot replace that Decision. Minimal receipts survive applicable content purge; text retention does not rewrite historical authority.
